Интерактивный процесс Витавто — роли, статусы, покрытие кода

B5: схема-дорожки + плеер сценария + слой «есть / частично / нет» в расширении АРМ. Канон: ТЗ + блок-схема + матрица прав + src/. Не подключено к 1С.
← Матрица прав
есть в коде АРМ частично нет / разрыв клик по узлу — детали ТЗ / матрица / код
Сценарии плеера — 0 группы + фильтр; карточка или выпадающий список
Выберите сценарий и нажмите «Плей» или кликните узел
Плеер подсвечивает путь заявки по блок-схеме и синхронизирует панель справа.
Дорожки = роли со схемы. Стрелки сценария видны в панели «Переходы» справа. Пунктир на схеме = согласование / обратный поток.
Вторая страница блок-схемы: физическое движение деталей по зонам склада.
Кликните узел на схеме или запустите плеер — здесь появятся ТЗ, статусы матрицы, колонки и факт в коде.
Источники: ТЗ Витавто, витвто.drawio, матрица колонок, gap-анализ src/ (АС_АРМ2). Покрытие — экспертная оценка по распакованному расширению, не runtime-метрика.
