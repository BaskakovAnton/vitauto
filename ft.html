Как читать: идентификатор FR → пункт(ы) протокола → формулировка для разработки и приёмки. Детали UI (имена кнопок в 1С) уточняются на пусконаладке; бизнес-смысл не менять без C5.

FR-SCOPE. Границы и платформа

Трассировка к БТ: BR-1, BR-6

FRПротоколТребование
FR-SCOPE-01S1Контур v1: заказ покупателя + АРМ + складские статусы/колонки без механика.
FR-SCOPE-02S2Контур механика / нормочасов не реализуется в v1 (later); комментарий S2 — в backlog.
FR-SCOPE-03S3В НСИ поддерживаются все 6 складских зон схемы.
FR-SCOPE-04S4,S5,S8ПФ этапа печати, сайт поставщика, обмен с внешней бухгалтерией — не реализуются.
FR-SCOPE-05S7Целевая платформа: 1С:УНФ 1.6 (уточнить конфликт с комментарием «свежая редакция»).
FR-SCOPE-06S6Документ внутренних нужд / теги КА — не в объёме до отдельного апрува.

FR-PRICE. Ценообразование

Трассировка к БТ: BR-4

FRПротоколТребование
FR-PRICE-01B1В строке заказа: коэффициент наценки, вводимый вручную.
FR-PRICE-02B1Если РРЦ (рекомендованная розничная цена) не указана — цена = себестоимость × коэффициент.
FR-PRICE-03B1Если РРЦ указана — цена = РРЦ × коэффициент.
FR-PRICE-04B1Если пользователь задаёт цену напрямую — коэффициент пересчитывается относительно себестоимости и проставляется.

FR-MATCH. Сопоставление номенклатуры

Трассировка к БТ: BR-3, BR-4

FRПротоколТребование
FR-MATCH-01B2Сопоставление «номенклатура факт → справочник» — отдельная обработка в интерфейсе АРМ (не в форме заказа как единственный UX).
FR-MATCH-02B2Основной рабочий контур незакрытых позиций — АРМ; при ошибке — корректировка и возврат в контур заказа/АРМ.

FR-ORDER. Заказ покупателя

Трассировка к БТ: BR-3, BR-4

FRПротоколТребование
FR-ORDER-01O1Загрузка/вставка заявки ctrl+c/ctrl+v с проверкой типов данных (формат «как УКД» / согласованные колонки).
FR-ORDER-02O2Поля: гос. номер, срочно, база — по образцу 1с.xlsx.
FR-ORDER-03O3Срочность — визуальная метка (без отдельной бизнес-логики закупа по срочности).
FR-ORDER-04O4Резерв только по кнопке; если указано «хочет продать» и есть на складе — постановка в резерв по правилам кнопки.
FR-ORDER-05O5Снятие с резерва — только создатель, по кнопке.
FR-ORDER-06O9Кнопка «Добавить строку заказа»: частичный резерв имеющегося + новая строка на недостающее.
FR-ORDER-07O10Проведение/поведение проведения — типовое УНФ, без отдельной кастомной схемы (если не пересекается с B3).
FR-ORDER-08O11Одна деталь с разными поставщиками/ценами — возможность выбора варианта в строке.
FR-ORDER-09O12Колонка AD (доп. признак) — по согласованному смыслу из комментария.
FR-ORDER-10O13Универсальный текстовый столбец комментария.
FR-ORDER-11O14 outАвтоконтроль «верно ли сопоставили» — не требуется.

FR-ARM. АРМ менеджера / снабжения

Трассировка к БТ: BR-2, BR-3

FRПротоколТребование
FR-ARM-01A1АРМ показывает незакрытые позиции контура продаж (включая связанные заказ-наряды в списке — без реализации механика).
FR-ARM-02A2 outОтдельные колонки «дозаказать / остаток / в пути» как требование A2 — out (не путать с прочим гридом).
FR-ARM-03A3,A5,A6Грид АРМ: согласованные колонки; набор колонок — «свой список» по 1c.xls; обновление данных — да.
FR-ARM-04A7Доступ к действиям/колонкам — по матрице прав.
FR-ARM-05A8Фильтры на все поля грида.
FR-ARM-06A9Группировки/представления — да (как утверждено).
FR-ARM-07A10 outМассовая установка статуса «Заказано» с ПКМ — не делаем.
FR-ARM-08A11Предварительный сбор требований (листики) — в v1.
FR-ARM-09A12Отдельный UX «возврат как заказ от клиента» в АРМ — нет; возвраты — по контуру R* / принципу комментария A12 не как отдельная FR-форма A12.
FR-ARM-10A13Отказ/отмена — метка «Отменен» / «заказчик отказался» без сложного алгоритма.
FR-ARM-11A14Удаление позиций/документов пользователем запрещено.
FR-ARM-12A4 outСоздание расходной накладной набором из АРМ — out.

FR-BUY. Закуп / заказ поставщику / приёмка

Трассировка к БТ: BR-3, BR-4

FRПротоколТребование
FR-BUY-01B3Создание заказа поставщику — только вручную/кнопкой из АРМ.
FR-BUY-02B3Сценарий: заказ клиента → привязка к нашей номенклатуре → при отсутствии на складе указание кол-ва к закупке (комментарий B3).
FR-BUY-03P1Алгоритм закупа не учитывает срочность.
FR-BUY-04P4Создание/ведение ЗП — из АРМ.
FR-BUY-05P5Заполнение ключевых полей ЗП — всегда вручную; колонка AD — проверить расчёт 1С.
FR-BUY-06P6Сортировка/группировка поставщиков — по алфавиту (Максим).
FR-BUY-07P7Связь ЗП со строкой покупателя — как в текущем коде (без ломки), с донастройкой по апрувам.
FR-BUY-08P8Подсказки аналогов со связью без отдельного справочника «как сущность».
FR-BUY-09P9Если позиция есть — показать у кого и за сколько; при отличиях — сигнализировать (проверить реализацию).
FR-BUY-10P2,P3,P10 outУчёт поставщика при вводе на основании / снятие «по основанию» / виртуальный закуп — out.

FR-WH. Склад / комплектация / отгрузка

Трассировка к БТ: BR-3

FRПротоколТребование
FR-WH-01B4Отображение движения — столбцы (оплата, приёмка, return и др. по матрице/process), не только короткий enum статусов.
FR-WH-02W1,W2,W3Комплектация/складские шаги — как в ТЗ для утверждённых пунктов W1–W3.
FR-WH-03W4Напоминания — внутренними средствами 1С (отдельный notify).
FR-WH-04W5,W8,W9Сценарии склада/отгрузки по утверждённым W5,W8,W9.
FR-WH-05W7Привязка к зоне: достаточно статуса/колонки без обязательной зоны в каждом шаге.
FR-WH-06W6 outФормирование РН из АРМ как отдельное требование W6 — out.
FR-WH-07B5Роль исполнителя склада в v1 = «кладовщик-грузчик».

FR-RET. Возвраты

Трассировка к БТ: BR-3

FRПротоколТребование
FR-RET-01R1Если нет документов на возврат — кладовщик идентифицирует позицию.
FR-RET-02R2Заявку на возврат поставщику могут создать менеджер и кладовщик.
FR-RET-03R3Возврат клиента — да (по утверждённому сценарию).
FR-RET-04R4Операции возврата из АРМ — по роли.
FR-RET-05R5,R6 outВозврат на склад без возврата поставщику как отдельный сценарий и ПФ/акты возвратов — out.

Трассировка к БТ: BR-1, BR-4

FRПротоколТребование
FR-NSI-01N3Доработка номенклатуры новыми полями — проверить/довести реализацию.
FR-NSI-02N4Наименование/поля для печати из файла «БТ» — проверить работоспособность (без пакета печатных форм S4).
FR-NSI-03N6Поле правил — донастроить.
FR-NSI-04N8Поле на уровне номенклатуры есть; внешняя интеграция — later.
FR-NSI-05N9Рекомендация ед. изм. шт на складе без жёсткого запрета.
FR-NSI-06N1,N2,N5,N7 outРРЦ только в карточке как отдельное N1, фото неопознанных, запрет бренда КАМАЗ, группа ГБЦ — out.
