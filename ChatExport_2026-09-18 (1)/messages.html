Доработки в документе «Заказ покупателя»
 
В документе «Заказ покупателя» наряду с существующими доработками будут произведены следующие доработки для удобства пользователя:
1. Исправление ошибок при загрузке данных в документ из файла.
2. Замена колонки «Остаток» колонкой «Можно отгрузить» со сменой выводимого наименования на «Остаток» в табличной части документа.
3. Добавление колонки с партией в табличной части документа.
4. В табличной части документа отображение себестоимости партии в строке с товаром, деление строк по количеству, исходя из остатка партии.
5. Добавление колонки с % НДС входящей по партии в табличной части документа.
6. При нажатии кнопки «Подбор» изменить стандартный функционал: вместо добавления новой строки подбор будет производиться в текущую строку.
7. Скрытие на форме следующих полей табличной части: «Свободно для резерва», «В резерве», «Скидка».
8. Добавление в табличную часть колонки «Заказано (статус)»
9. Разработка механизма автоматического добавления строк при нехватке остатков товара.
10. Добавление кнопки для добавления строк при нехватке остатков товара
11. Добавление функционала: при нажатии правой кнопки мыши выставление статуса в колонке «Заказано (статус)» для всех выделенных строк.
12. Разработка функционала: создание документа «Заказ поставщику» при проведении документа «Заказ покупателя» в случае, если в табличной части документа добавлены строки для дозаказа недостающих номенклатурных позиций.
13. Настройка ролей при работе с документом.
Сценарий использования документа «Заказ покупателя»:
1. Пользователь создает новый заказ.
2. Производит загрузку данных из файла, заполняя документ. Заполняются колонки табличной части «Номенклатура факт» (тип строка), «Артикул факт» (тип строка) и «Количество факт» (тип число).  
3. Пользователь в документе в табличной части подбирает в колонку «Номенклатура» номенклатуру из базы, сопоставляя загруженной из файла номенклатуре (Номенклатура факт).  Автоматический контроль корректности сопоставления номенклатуры не предусматривается.
4. В случае, если остатков по сопоставленной номенклатурной позиции не хватает, автоматически добавляется новая строка табличной части, в которой колонки «Номенклатура факт», «Артикул факт», «Количество факт», а также «Номенклатура» дублируются из предыдущей строки, в поле «Количество» записывается недостающее количество (значение можно менять вручную). В такой строке в столбце «Заказано (статус)» будет автоматически выставлен статус «Заказано».
5. Если пользователь не изменит строку в п.4, или изменит значение в колонке «Количество» в большую сторону, то при дальнейшем проведении документа требуемое (указанное) количество будет заказано (будет автоматически создан документ «Заказ поставщику» с требуемым количеством).
6. Если пользователь в строке из п.4 изменит количество в меньшую сторону, то по аналогии с п.4 будет создана строка, в которой колонки «Номенклатура факт», «Артикул факт», «Количество факт», а также «Номенклатура» дублируются из предыдущей строки, в поле «Количество» записывается недостающее количество (значение можно менять вручную). В такой строке в столбце «Заказано (статус)» будет автоматически выставлен статус «Заказано». Т.е. новая строка будет автоматически добавляться пока: а) пока недостающее количество товара не будет заказано. б) если пользователь не поменяет номенклатурную позицию на аналог, остатков которого достаточно для продажи.
15:12
7. Пользователь может добавить строки для дозаказа недостающих номенклатурных позиций с помощью кнопки. Для этого пользователь встает на нужную строку табличной части и нажимает кнопку на панели задач «Добавить строку заказа». Ввод таких строк по количеству неограничен. При этом, как и в предыдущем пункте п.6 , из исходной строки будут копироваться следующие колонки: «Номенклатура факт», «Артикул факт», «Количество факт», а также «Номенклатура». В таких строках в столбце «Заказано (статус)» не будет автоматически выставлен статус «Заказано». При добавлении строк дозаказа по кнопке статус устанавливает пользователь вручную. Т.к. таких строк может быть много, пользователь может выделить с Ctrl несколько строк и при нажатии правой кнопкой мыши, может выбрать установку статуса заказа для всех выделенных строк.
8. Пользователь проводит документ. По всем позициям количество резервируется.
9. Пользователь не может отменять проведение у документа. Соответственно, пользователь не может пометить документ на удаление. Проведенный документ не может быть изменен пользователем. Для пользователя данная операция будет доступна только через обработку «Арм». Механизм будет рассмотрен при описании работы с «Арм». У пользователя с наивысшими правами (специально разработанная роль) будет возможность производить с документом любые операции.
